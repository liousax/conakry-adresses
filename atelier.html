Atelier du référentiel

1Télécharger les rues

Limites des communes, quartiers, puis les rues par carreaux. Compter 3 à 15 minutes. Si la connexion coupe, relancez : les carreaux déjà reçus sont gardés.

Prêt.

2Vérifier

Aucune version précédente publiée : tous les codes sont nouveaux.

Limite de : cliquez sur l'aperçu pour placer les coins, dans l'ordre (0 point). Double-cliquez ou « Terminer » pour finir.

3Publier

Le zip contient le dossier data (pour une ville de l'intérieur, son sous-dossier, par exemple data/labe) : index.json (communes, quartiers, limites), voies.json (rues et numérotation), sources.json (pour garder les mêmes codes à la prochaine génération) et villes.json (les villes en ligne). Dans GitHub, sur l'accueil du dépôt : « Add file → Upload files », glissez le dossier data, puis « Commit changes ».

« Noms proposés » : la liste des rues renommées, avec leur ancien numéro, leur quartier et la personnalité honorée, à ouvrir dans Excel pour la soumettre aux communes.
